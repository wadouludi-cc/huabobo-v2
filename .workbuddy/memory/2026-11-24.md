## 旋转改绕世界轴 + 方向提示（同一天第二笔）

- 现象：用户反馈「Z 轴旋转和 X 轴一样」，三根轴图标都是同一个 lucide `rotate-3d`，旋转时看不出方向。
- 根因：原来用 `w.rotation.x/y/z += rad` 累加 Euler（order XYZ），Z 旋转作用在模型自身局部轴上；先转过 X 后，局部 Z 已经不是世界 Z，看起来就跟另一根轴一样。
- 改法（`frontend/js/studio.js`）：
  - `applyModelRotation` 改成四元数左乘：`new Quaternion().setFromAxisAngle(worldAxis, rad).multiply(wrapper.quaternion)`，永远绕世界轴，方向可预期。
  - 新增 `rotationTweens`（220ms slerp 缓动）+ `animate(now)` 里推进，15° 步进能看出动作。
  - 新增 `showRotationHint`：模型中心画「150° 弧形箭头 + 轴心线」，弧线在各自的旋转平面里，按轴取色（X 红 0xc9414f / Y 绿 0x3f8f5f / Z 蓝 0x2f6fbf），`depthTest:false + renderOrder 999` 保证不被模型挡住，约 1s 淡出；Y 轴的环抬到模型 72% 高度，弧线朝镜头一侧（arcCenter = -0.7π），避免趴案板上被遮挡。
  - 状态栏改成带方向说法：`已绕 Y 轴右转 15°（Y 轴累计 45°）`；每件模型 `axisDeg` 记累计角。
- 图标：`frontend/studio.html` 三个按钮换成内联 SVG（X 竖椭圆+横轴线 / Y 横椭圆+竖轴线 / Z 圆+圆心点），`frontend/css/studio.css` 加 `.studio-axis-icon` 系列样式与按轴配色；操作提示卡加一行「旋转按轴分色：X Y Z」。
- 版本号：studio.js、studio.css 都提到 `20261124b`。
- 验证：本机 Chrome 截图三个轴（1092×588 与 1280×800），确认弧线/箭头/轴心线可读、Z 轴在 X 转 90° 后仍是绕世界 Z 翻滚；Pixel 5 竖屏按钮只显示图标也分得清；`e2e/tests/studio.spec.js` 通过（需后端跑在 3000）。
