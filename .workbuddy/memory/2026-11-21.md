## 新功能：收货地址 + 地址变更审核

需求：我的主页「修改昵称」旁新增添加收货地址（姓名/手机号/地址）；订单默认采用该地址；地址可二次修改，但需管理员审核，同意后新地址生效、驳回则保留原地址；进行中的订单不支持换地址；后台能看到地址并在用户提交修改时收到提醒。

### 数据层
- `schema.sqlite.js` / `schema.pg.js`：新增 `user_addresses`（userId 唯一，name/phone/address）、`address_change_requests`（old*/new*/status/reviewedBy/reviewedAt）；`custom_orders` 增加 `ship_name/ship_phone/ship_address` 快照列。
- `db/client.js`：两套分支都补了 CREATE TABLE / 补列（SQLite 用 PRAGMA 检查后 ALTER），沿用「不跑 drizzle 迁移」的项目惯例。

### 后端
- 新增 `routes/addresses.js`：
  - 用户：`GET /api/addresses/mine`（默认地址 + 待审核申请）、`PUT /api/addresses/mine`（首次直接生效 mode=saved；已有地址则生成 pending 申请；重复提交 409）、`DELETE /api/addresses/mine/request`（撤销申请）。
  - 管理员：`GET /api/admin/addresses`（待审核列表 + 全部用户地址）、`GET /api/admin/addresses/pending-count`（红点）、`PATCH /api/admin/addresses/requests/:id`（action=approve/reject，approve 时 upsert 用户地址）。
  - 校验：手机号 `^1[3-9]\d{9}$`、地址≥5 字。
- `routes/customOrders.js`：下单前必须有地址（否则 400 `code=ADDRESS_REQUIRED`），并把地址快照写进订单，保证进行中的订单不受地址变更影响；`/mine`、管理员列表/详情返回 `ship`；详情额外返回 `currentAddress` 与 `pendingAddressChange`。

### 前端
- `profile-page.js`：昵称按钮旁新增「添加/修改收货地址」按钮，展开内联表单（姓名/手机号/地址），下方常驻地址摘要 + 「新地址审核中」徽标；审核中可撤销；订单卡片显示「配送至：…（进行中订单不支持更换地址）」；地址状态随 15s 轮询与 visibilitychange 同步刷新。
- `api.js` / `api-remote.js`：新增 `getMyAddress` / `saveMyAddress` / `cancelAddressRequest`；本地兜底模式用 `zhijiansu_address(_pending)` 存 localStorage，无地址下单同样返回 ADDRESS_REQUIRED。
- `artisan-co-page.js`：下单区显示「本单配送地址：…（可在我的主页修改）」，推送前先查地址，缺失时提示并给出我的主页链接。

### 后台
- `admin/index.html`：侧边栏新增「地址审核」+ 红点 `#address-nav-badge`，新增 `#panel-addresses`（待审核申请 / 用户当前地址两张表）。

### Git 分叉处理
- 现象：`origin/main` 上的 `72c13e7 dingdan` 与本地 `a85d805 dingdan` patch-id 完全相同（`1edcf7e9…`），属同一次提交被提交两遍，导致 main 分叉（本地 2 / 远端 1）。
- 处理：先 `git branch -f backup-before-rebase c57f2bc` 备份，再 `git rebase --onto origin/main a85d805 main`，只把「地址」提交重接到远端之上。结果 `3ec2c2e 地址` 位于 `72c13e7` 之上，tree 哈希与重接前一致（`c004991…`），历史线性化。
- 推送未完成：非交互环境无 GitHub 凭证（keychain 无 github.com 项、gh 未安装），`git push` 报 `could not read Username`。需用户在本地终端手动 `git push origin main`。
- 遗留：本地分支 `backup-before-rebase` 为安全备份，确认无误后可 `git branch -D backup-before-rebase`。
