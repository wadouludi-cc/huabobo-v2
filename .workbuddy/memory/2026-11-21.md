# 2026-11-21 工作日志

## 新功能：DIY 作品定制订单（推送手艺人 → 后台订单管理）
需求：用户在作品页选择合作手艺人，把手作推送给对方；「我的」页面显示正在定制的订单；后台新增订单管理，可看订单照片与 3D 模型并改状态，前端实时同步。四种状态：正在接单 / 已接单制作 / 准备派送 / 已完成。

### 后端
- `backend/src/db/schema.sqlite.js`、`schema.pg.js`：新增 `custom_orders` 表（id/workId/userId/artisanId/artisanName/note/status/createdAt/updatedAt），带 user/status 索引。
- `backend/src/db/client.js`：SQLite 与 PG 分支都加了运行时 `CREATE TABLE IF NOT EXISTS custom_orders` + 索引（项目惯例：不依赖 drizzle 迁移文件建新表）。
- 新增 `backend/src/routes/customOrders.js`：
  - `POST /api/custom-orders`（requireUser，校验作品归属，只能推自己的作品）
  - `GET /api/custom-orders/mine`（我的订单，含作品封面，不含 3D 大字段）
  - `GET /api/admin/custom-orders`（列表）、`GET /api/admin/custom-orders/:id`（详情，含 work.studio 3D 快照）
  - `PATCH /api/admin/custom-orders/:id`（状态白名单校验）
  - 状态枚举 `pending/accepted/delivering/completed` → 中文标签映射在 `STATUS_LABEL`
- `backend/src/index.js`：挂载 `/api/custom-orders`、`/api/admin/custom-orders`。
